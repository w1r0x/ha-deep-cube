# Кубик сна deep для Home Assistant

[English](README.md) | **Русский**

Неофициальная интеграция Home Assistant для кубика сна deep. Управление локальное, по Bluetooth LE, без облака и аккаунта производителя.

Проект не связан с производителем устройства. Протокол восстановлен наблюдением за обменом собственного устройства автора с официальным приложением deep up; описание — в [docs/protocol.md](docs/protocol.md) (на английском).

## Поддерживаемые устройства

| Модель | Состояние |
| --- | --- |
| deep.r | Проверена, прошивка 1.8.9 |
| deep.n | Обнаруживается и настраивается так же, но **не проверена**: у автора такого устройства нет. Пожалуйста, [создайте issue](https://github.com/w1r0x/ha-deep-cube/issues) и расскажите, как она у вас работает |

## Требования

- Home Assistant 2025.2 или новее.
- Bluetooth-адаптер или [ESPHome Bluetooth Proxy](https://esphome.io/components/bluetooth_proxy.html) с включёнными активными соединениями в зоне действия кубика.

## Установка

### HACS (пользовательский репозиторий)

1. В HACS откройте меню в правом верхнем углу и выберите **Пользовательские репозитории**.
2. Добавьте `https://github.com/w1r0x/ha-deep-cube` с типом **Интеграция**.
3. Найдите в HACS **deep sleep cube**, скачайте и перезапустите Home Assistant.

### Вручную

Скопируйте папку `custom_components/deep_cube` в папку `custom_components` конфигурации Home Assistant и перезапустите Home Assistant.

## Настройка

1. Закройте приложение deep up на телефоне: кубик принимает одно соединение и не виден, пока к нему подключено приложение.
2. Home Assistant сам найдёт кубик и предложит добавить его в разделе **Настройки → Устройства и службы**. Если этого не произошло, нажмите **Добавить интеграцию** и выберите **deep sleep cube**.

Интервал опроса (по умолчанию 5 минут) меняется кнопкой **Настроить** на странице интеграции.

## Сущности

| Сущность | Тип | Назначение |
| --- | --- | --- |
| *(имя устройства)* | переключатель | Главный переключатель кубика: включение запускает выбранную программу до времени пробуждения, выключение останавливает идущую программу |
| Программа | выбор | Программа для следующего запуска |
| Время пробуждения | время | Запущенная программа работает до ближайшего наступления этого времени |
| Интенсивность | выбор | Интенсивность для следующего запуска: низкая, нормальная или максимальная. По умолчанию скрыта |
| Текущая программа | датчик | Программа, которая идёт сейчас, в том числе запущенная из приложения |
| Окончание программы | датчик | Когда закончится идущая программа |
| Батарея | датчик | Заряд батареи |
| Светодиодная индикация | переключатель | Настройка кубика. По умолчанию скрыта |
| Выключать индикацию через 20 сек | переключатель | Настройка кубика. По умолчанию скрыта |
| Вибрация | переключатель | Настройка кубика. По умолчанию скрыта |

Скрытые по умолчанию сущности — редко меняемые настройки: они доступны на странице устройства, но не попадают на автоматически создаваемые панели. Сделать их видимыми можно в настройках сущности.

Программа, время пробуждения и интенсивность хранятся в Home Assistant и передаются кубику только при запуске программы — так же поступает официальное приложение.

Состояния сущностей не зависят от языка интерфейса, поэтому автоматизации работают на любом языке: программы — `just_sleep`, `bear_sleep`, `dream_whale`, `dreamcatcher`; интенсивность — `low`, `normal`, `max`.

## Действия

`deep_cube.start_program` запускает программу одним вызовом. Все параметры, кроме устройства, необязательны; пропущенные берутся из сущностей выше.

```yaml
action: deep_cube.start_program
data:
  device_id: <ваш кубик>
  program: bear_sleep
  intensity: low
  wake_time: "07:30:00"
```

`deep_cube.stop_program` останавливает идущую программу.

```yaml
action: deep_cube.stop_program
data:
  device_id: <ваш кубик>
```

## Как это работает и что нужно учитывать

- Кубик принимает одно Bluetooth-соединение. Интеграция подключается только на время опроса или команды и сразу отключается, поэтому приложение deep up остаётся рабочим. Пока к кубику подключено приложение, Home Assistant до него не достучится, и сущности будут недоступны до следующего успешного опроса.
- Состояние обновляется опросом, поэтому изменения, сделанные в приложении или кнопкой на кубике, появляются с задержкой до интервала опроса. После команды из Home Assistant состояние читается сразу.
- Поддерживаются четыре программы: «Просто сон», «Сон медведя», «Дрим кит» и «Ловец снов». Идентификаторы остальных программ пока неизвестны. Незнакомая интеграции программа, запущенная из приложения, показывается как «Другая».
- Английские названия программ — перевод автора, они могут отличаться от официальных.
- У кубика нет часов: время пробуждения пересчитывается в длительность в момент запуска.
- Слишком короткие программы кубик молча игнорирует (2 минуты игнорируются, 30 минут работают). Интеграция проверяет, что программа действительно запустилась, и сообщает об ошибке, если нет.
- Время окончания известно с точностью около 0,1 % длительности программы — примерно минута для программы на ночь.

## Языки

Интерфейс доступен на английском и русском и следует языку вашего профиля Home Assistant. Чтобы добавить язык, скопируйте `custom_components/deep_cube/translations/en.json` в `<код языка>.json`, переведите значения и откройте pull request. Менять код не нужно.

## Решение проблем

- **Кубик не находится.** Закройте приложение deep up, проверьте, что кубик заряжен и находится в зоне действия адаптера или прокси.
- **Сущности недоступны или команды завершаются ошибкой «Не удалось связаться с кубиком».** Слабый сигнал либо соединение занято приложением. Перенесите адаптер или прокси ближе.
- **Другое.** Скачайте диагностику на странице интеграции и [создайте issue](https://github.com/w1r0x/ha-deep-cube/issues). Адреса кубика в диагностике нет.

Чтобы увидеть обмен с кубиком в журнале:

```yaml
logger:
  logs:
    custom_components.deep_cube: debug
```
